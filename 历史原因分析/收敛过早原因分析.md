# ACO-GTSP 收敛过早（水平直线）原因分析

> 对应版本：CPP Arena 1.2.1　|　数据集：一个凹多边形（6 个凸子区，25 个节点）

## 一句话结论

收敛曲线在**第 0 代就变成水平线**，是**程序实现 / 默认配置问题，不是 ACO 算法或论文参数的问题**。蚁群一开始就早熟锁死在"最近邻贪心"次优解上，之后 500 代无法改进。

## 现象

- `best_iteration = 0`，500 代曲线完全不变。
- 停在区域间转运距离 **2488 m**；动态规划求出的精确最优是 **1733 m**，次优约 **44%**。
- 说明不是"第 0 代就找到最优"，而是"第 0 代就卡死"。

## 四个原因

1. **探索因子被关闭（主因）**：论文 §3.4 的"随机因子"对应参数 `exploration_prob` 被默认设为 `0`，蚁群从第 0 代起就纯贪心、不再探索。
2. **β=20 过于贪心**：启发度 η 的 20 次方动态范围约 1e42，选择概率几乎只压在最近点上（首步有效选择数仅约 3/24），所有蚂蚁走出几乎相同的路径。
3. **信息素尺度失配**：初值 `τ0=1`，而每轮沉积 `Q/L≈6e-6`，相差约 1.7e5 倍；信息素正反馈被 η²⁰ 碾压，蚁群"学不动"。
4. **信息素更新顺序错误**：蚂蚁逐只在线沉积、轮末才统一挥发，当轮沉积被额外乘 0.3，也不符合论文"全部蚂蚁走完再统一更新"的 ANT-cycle 流程。

## 机制链

```
①探索关闭 + ②β=20贪心  →  选择多样性坍缩（整群蚂蚁路径雷同）
③尺度失配 + ④更新错误  →  正反馈失效（好边强化不出来）
                  ↓
        第 0 代锁死在贪心次优解 → 水平直线
```

## 为什么不是算法本身的问题

论文同一套参数（α=0.5、β=20、ρ=0.7、Q=1）本就靠"随机因子"保证前期探索。复现程序把该因子关掉才导致锁死；补回探索、修正信息素更新后（**四个论文参数均未改动**），曲线即正常下降并命中精确最优。

## 修复（详见 CHANGELOG 1.2.1）

- 恢复探索并随迭代衰减（初始 0.5，余弦衰减到 0），探索步用 RCL 受限候选表。
- 改为标准批量 ANT-cycle；新增全局最优精英沉积。
- 最近邻贪心兜底，结果永不劣于贪心；`τ0` 自动标定。

**效果**：约 28–73 代收敛到精确最优 1733 m（gap≈0%），曲线恢复"前期阶梯下降、后期平稳走平"。

---

> 附注：曲线纵轴里程曾虚高约 4 倍（每个子区 4 个备选方案的内部里程被重复累加）。这是另一个**统计/显示口径 bug**，只影响纵坐标绝对值，不影响选优和曲线形状，已一并修复。
