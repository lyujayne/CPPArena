# CPP Arena History Viewer v2.9

这是完全独立的离线历史实验平台。直接双击 `start.bat`，或执行：

```powershell
python viewer.py
python viewer.py "D:\experiments\20261020_091011_覆盖实验"
python viewer.py "D:\experiments\example.cppx"
```

运行环境依赖见 `requirements.txt`。当前电脑已安装这些依赖，无需再安装。
整份 `HistoryViewer` 文件夹可复制到其他位置运行；不需要主程序目录、主程序 exe 或算法源码。

主程序完整导出时提示实验名称，生成“时间_实验名称”文件夹，直接保存到本平台默认 `experiments` 实验库。本机现有上级独立平台与主程序仓库副本共享 `E:\workspace\fly\CPP Arena\HistoryViewer\experiments`。把整份平台复制到其他位置后，使用该副本自身的 `experiments`。

通过“导入实验文件夹”选择包含 `experiment.json` 的完整文件夹；外部目录会完整复制到默认库，原文件移动或平台重启后仍能回放。通过“导入旧实验包”兼容 `.cppx/.zip/.json`，旧记录来源版本保持不变。新记录每2秒自动发现，也可点击“刷新实验库”；“打开默认实验库”可查看实际保存位置。

v2.5导入JSON时只保存原始实验快照并复制底图，不再重新生成全部运行的高清图片和航点附件。已有完整文件夹/ZIP的附件仍完整保留；需要图片或航点时可从回放界面导出。缺失底图会提示具体路径，导入失败不会留下半成品。回放先恢复保存的图层、分割开关和所选运行，减少大规模实验重复绘制。

显示平台优化（主平台版本仍为2.5）：选择实验后在后台读取，连续切换时以最后一次选择为准。缓存最近两个实验，文件更新后重新读取；重复点击当前实验不会重绘。已有路线指标直接复用，旧记录缺少的指标在读取时补算。

超过8个可见组合时，默认用批量总览显示全部轨迹、方向及入口/出口点，颜色与组合开关一致，避免数千个编号遮住地图。选择单个组合后显示完整编号与细节，也可勾选“完整叠加标注（较慢）”恢复全部详细标注。独立显示平台的优化不递增主平台版本号。

选择数据集、组合和种子后，可查看轨迹、分割、入/出口、覆盖率、指标、收敛曲线及日志。覆盖率=扫描到的目标面积/总任务面积；悬停查看面积明细。微小未覆盖面积保留非零精度，错误日志标红。
地图上方“显示路径规划组合”使用可多选的下拉列表，打开实验或切换数据集时默认全部不勾选，按需勾选后显示路线。列表按路线颜色显示组合名称；组合较多时上下滚动勾选，无需左右拖动，按钮显示已选数量。
支持回放v2.3新增分割与DBO、SSA、GS-IPSO、IDGWO-VNS的已保存结果；算法名悬停可查看实现范围。无需安装SciPy或加载算法，也不重新求解。旧实验来源版本保持不变。
v2.4对比表保留失败与部分失败组合并标红，新增运行状态和失败次数；仅成功结果参与数值统计及图表。错误信息为固定高度的可滚动区域，条数增多不会挤压结果表。
旧实验缺少入口/出口字段时，平台直接使用已保存内部路径的首尾点补绘标记，不重新计算算法。

图中绿圆为入口，橙方为出口，编号对应子区域访问顺序；可通过开关隐藏。运行结果完全由实验文件还原，平台不加载算法、不联网下载底图。

`runtime` 内包含本平台所需的显示及数据读取代码，是独立副本。主程序不再包含历史平台入口或 `--history` 模式。此前 exe 保留原样，本次仅更新源码。

共享功能已同步v2.6：收敛曲线支持勾选组合批量/叠加导出高清JPEG；指标提示包含优劣方向，无漏扫覆盖率展示与CSV统一消除浮点尾差。
