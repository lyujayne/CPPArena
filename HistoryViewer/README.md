# CPP Arena History Viewer

这是完全独立的离线历史实验平台。直接双击 `start.bat`，或执行：

```powershell
python viewer.py
python viewer.py "D:\experiments\example.cppx"
```

运行环境依赖见 `requirements.txt`。当前电脑已安装这些依赖，无需再安装。
整份 `HistoryViewer` 文件夹可复制到其他位置运行；不需要主程序目录、主程序 exe 或算法源码。

通过“打开实验包”导入 `.cppx` / `.zip`，通过“扫描文件夹”集中管理历史记录。选择数据集、组合和种子后，可查看轨迹、分割、入/出口、指标、参数、收敛曲线及日志。
旧实验缺少入口/出口字段时，平台直接使用已保存内部路径的首尾点补绘标记，不重新计算算法。

图中绿圆为入口，橙方为出口，编号对应子区域访问顺序；可通过开关隐藏。运行结果完全由实验文件还原，平台不加载算法、不联网下载底图。

`runtime` 内包含本平台所需的显示及数据读取代码，是独立副本。主程序不再包含历史平台入口或 `--history` 模式。此前 exe 保留原样，本次仅更新源码。
